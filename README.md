# Data Cleaning AI Agent

## Objective
This project cleans raw CSV data automatically using Python and Pandas.

## Features
- Removes duplicate records
- Removes extra spaces
- Standardizes names and city names
- Converts Age and Salary into numeric values
- Fills missing values
- Generates a cleaned CSV output file

## Tools Used
- Python 3
- Pandas
- CSV

## Input
sample_input.csv

## Output
cleaned_output.csv

## How to Run

Install the required library:

pip install -r requirements.txt

Run the program:

python data_cleaning_agent.py

## Result
The agent reads the raw CSV file, cleans the data, and saves the cleaned data into cleaned_output.csv.
